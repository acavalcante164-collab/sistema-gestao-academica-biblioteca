# Projeto Referente a Disciplina DCC 502 da UFRR

![CAPA DO TRABALHO](imagens/IMAGEM.jpg)

Este projeto apresenta a implementação de tudo que foi abordado na disciplina de Banco de Dados I.

A descrição e requisitos do projeto estão disponíveis em [specs/](specs/ESPECIFICAÇÃO%20DO%20TRABALHO%20PRÁTICO%20FINAL.pdf).

---
### Relatório Técnico

O SIGAB integra a gestão acadêmica e o controle de biblioteca de uma instituição de ensino superior. Este
[relatorio/](relatorio/Relatorio_Tecnico_SIGAB_Conferencia_Final.pdf) consolida a especificação do minimundo, o projeto conceitual, o mapeamento para 18 relações, o
memorial de normalização, o dicionário de dados Oracle e as evidências documentais da implementação e
dos testes.
A redação utiliza como referências os documentos técnicos, os cinco scripts SQL e o relatório de resultados
disponíveis no pacote do projeto. Contagens de objetos foram conferidas estaticamente nos scripts; a
execução informada no Oracle corresponde ao registro da equipe e não a uma execução independente
realizada durante esta revisão.
